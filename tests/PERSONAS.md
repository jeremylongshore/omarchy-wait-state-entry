# Test personas

- A developer compiling locally who needs to distinguish useful CPU work from
  runnable tasks stalled behind contention.
- An operator diagnosing reclaim or storage stalls without granting a desktop
  widget credentials or network access.
- A keyboard-first Omarchy user who expects every panel action without a mouse.
- A marketplace maintainer who needs exact-commit, bounded-runtime, and visual
  evidence rather than an unauditable claim that the plugin works.
