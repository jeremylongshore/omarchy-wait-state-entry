# Support

## Using Wait State

Start with the installation, controls, settings, and troubleshooting guidance in
the [README](README.md). Wait State requires Linux pressure stall information at
`/proc/pressure/cpu`, `/proc/pressure/memory`, and `/proc/pressure/io`.

## Reporting a problem

Open a GitHub issue with your Omarchy and kernel versions, the plugin version or
commit, relevant Quickshell log lines, whether each pressure file is readable,
and a screenshot when the problem is visual.

Do not include credentials, private paths, or unrelated logs. Use GitHub's
private vulnerability reporting for security issues as described in
[SECURITY.md](SECURITY.md).

This is a personal open source project without a guaranteed response time.
